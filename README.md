# HUB3D
A hub meant for anyone to find 3D printing designs and filter them based on whether they can be printed using a preset printer and filament setup, which is saved on a profile. This my first website, which I've used to learn basic HTML, CSS, JS, Bootstrap

# Necessity being addressed: Access to 3D printing.
Each user will be able to know which 3D designs are compatible with the printer(s) they have access to. For example, staff in my university would be able to print components that may require replacement, allowing them to repair appliances or other damaged elements. This can prevent them from having to buy whole new units or hiring technicians for avoidable costly repairs, lenghtening the useful life of said appliances. An example may be a broken vbacuum dust container.

# Target audience
Initially, students and staff from my university that may not have a 3D printer of their own, but could use the ones available in the campus.
